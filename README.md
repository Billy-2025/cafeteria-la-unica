# ☕ Café Central - Sistema de Gestión e Inventario

¡Bienvenido al repositorio de **Café Central**! Este proyecto es una aplicación web diseñada para digitalizar y optimizar las operaciones diarias de una cafetería, permitiendo administrar el menú, registrar los pedidos de los clientes y controlar el stock de insumos en tiempo real.

## 🚀 Características Principales

* **Punto de Venta (POS):** Interfaz rápida para que los cajeros tomen pedidos y generen tickets de compra.
* **Control de Inventario:** Alertas automáticas cuando ingredientes clave (como granos de café o leche) están bajos.
* **Menú Digital Dinámico:** Actualización en tiempo real de precios y disponibilidad de productos para los clientes.
* **Panel de Administración:** Gráficos con reportes de ventas diarias, productos más vendidos y horarios pico.

## 🛠️ Tecnologías Utilizadas

Este proyecto fue construido utilizando el siguiente stack tecnológico:

* **Frontend:** HTML5, CSS3, JavaScript (React)
* **Backend:** Node.js con Express
* **Base de Datos:** MongoDB
* **Estilos:** Tailwind CSS

## 📋 Requisitos Previos

Antes de ejecutar este proyecto de forma local, asegúrate de tener instalado:

* Node.js (versión 18.0 o superior)
* npm (gestor de paquetes de Node)
* Una cuenta o instancia local de MongoDB

## 🔧 Instalación y Configuración

Sigue estos pasos para configurar el proyecto en tu entorno local:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com
   ```

2. **Navegar al directorio del proyecto:**
   ```bash
   cd cafe-central
   ```

3. **Instalar las dependencias de Node.js:**
   ```bash
   npm install
   ```

4. **Configurar las variables de entorno:**
   Crea un archivo `.env` en la raíz del proyecto y añade tus credenciales (sigue el formato del archivo `.env.example`).

5. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

El sistema estará disponible en tu navegador en la dirección `http://localhost:3000`.
